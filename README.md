## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Running

```bash
# 1. Clone the repository
git clone https://github.com/giorgio0420/CVProject.git
cd CVProject

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
