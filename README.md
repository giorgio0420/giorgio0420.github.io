# Giorgio De Santis — Personal Portfolio & CV

A modern, high-performance personal portfolio built for **Giorgio De Santis** — Robotics Engineer, AI Developer, and Embedded Systems Specialist.

## 🚀 Tech Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Routing:** React Router v7 (`react-router-dom`)
- **Icons:** `lucide-react`
- **Styling:** Custom CSS Design System with Glassmorphism and CSS Variables (`src/index.css`)

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Production build
npm run build
```
